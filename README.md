# KiCad IA

Chat para armar el esquemático de KiCad. Describes el circuito y las piezas salen de las bibliotecas que ya tienes configuradas, no de una lista del plugin.

**Próximamente.** Esta página solo presenta esa idea.

[Página](https://krisskira.github.io/kicad-ia-pluging/) · [Código](https://github.com/krisskira/kicad-ia-pluging)

## La idea

- Las piezas salen de las bibliotecas configuradas en KiCad.
- El resultado es el esquemático del proyecto abierto.
- Si la pieza no está, no se dibuja una de mentira.

Quien esté desarrollando el plugin: el arranque y el mapa del código están en [`app/README.md`](app/README.md).
